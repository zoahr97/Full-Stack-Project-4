# React Visual Text Editor

**Academic grade: 95/100**

A React-based visual text editor that enables users to create, edit, style, save, and manage multiple text documents through an interactive interface.

The application provides real-time text preview while the user types and applies formatting. It includes a virtual keyboard with support for multiple languages, characters, symbols, and emojis. Users can customize font family, font size, and text color, as well as apply changes to new text or to the entire document.

The editor supports advanced editing tools such as deleting characters or words, clearing text, searching and replacing characters, and undoing recent actions. It also allows users to work on multiple documents simultaneously, switch between active documents, and close documents with an option to save changes.

Documents are saved and loaded using Local Storage. The application includes basic client-side authentication, so each user can access only their own saved text files.

## Key Features

- Real-time text editing and preview
- Virtual keyboard with multiple languages, symbols, and emojis
- Font, size, and color customization
- Text editing tools: delete character, delete word, clear text, undo
- Search and replace functionality
- Multiple document editing on the same screen
- Switch, focus, open, close, save, and load documents
- Local Storage-based document persistence
- Basic client-side authentication and user-specific files
- Modular React components and state management

## Technologies

**Frontend:** React, JSX, JavaScript, CSS  
**React Concepts:** Components, Props, State, Events, Rendering, Lists
